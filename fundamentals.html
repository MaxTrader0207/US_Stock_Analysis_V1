🚧 開發中 這個頁籤將加入巴菲特式的基本面選股邏輯，資料同樣會透過 Yahoo Finance API 定期抓取。以下為預計採用的篩選條件草案，實際數值與權重待補。
預計選股條件（草案）
01
長期穩定 ROE股東權益報酬率連續多年（如近5–10年）維持在 15% 以上，代表資本運用效率佳。
02
低負債比 / 財務體質健全負債權益比維持在合理水準（如 < 0.5），避免過度槓桿經營。
03
穩定且成長的自由現金流營運現金流持續為正，且自由現金流長期呈成長趨勢。
04
具備護城河 / 產業地位市占率領先、品牌力或轉換成本高，具備長期競爭優勢。
05
合理的估值本益比 / 自由現金流殖利率相對其歷史區間與同業具吸引力，避免追高。
06
管理層與股東利益一致持續且穩定的股利政策或庫藏股，經營層具備誠信紀錄。
